# My agent: OmniCRM (Universal Chat & Relationship Manager)
One-liner: A conversational agent that helps busy communicators manage contacts and interactions across WhatsApp, iMessage, Gmail, and Google Chat with style-matched draft recommendations and relationship insights.

Tool coverage:
- Memory: Contact history, per-person communication styles (tone, length, sign-offs, emoji usage), channel preferences, relationship notes, and follow-up reminders.
- Tools: Look up contacts, search message/interaction history across platforms, draft pre-recommended replies matching tone/channel, and schedule/log follow-up reminders.
- Catalog/UI: Contact directory, interaction history threads, suggested reply cards (with tone toggles and channel previews), and relationship status summary tables.
- Image gen: Contact avatar representations, visual relationship graphs / network connection cards, or visual message mood boards.
- Sandbox: Communication pattern analytics (response time trends, sentiment/tone score calculations, frequency analysis across platforms).

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for communication cadence analytics, external mock webhook/API integrations for messaging platforms, Cloud Trace for latency tracking.
